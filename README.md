## Adding a guide

1. Create a folder with a short, lowercase name, for example `my-new-guide/`.
2. Save the page as `my-new-guide/index.html`. Each guide is a single self-contained HTML file.
3. Add a footer with the last updated date and a pointer to the official documentation.
4. Add a card for it in the root `index.html` and a row in the table above.
5. Commit and push to `main`. GitHub Pages publishes it within a few minutes.

These are independent explainers, not official product documentation. Always check the official documentation linked in each guide for the latest information.
